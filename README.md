# Python Pytest QA Framework

Test automation framework built with Python and Pytest for QA.

## Requirements

- Python 3.10+
- pip

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install pytest
```

## Running the tests

```bash
pytest -v
```
