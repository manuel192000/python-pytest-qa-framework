# Claude Code: comandos útiles

Lista exacta de tu versión: `/help`.

| Comando | Qué hace | Cuándo usarlo |
|---|---|---|
| `/help` | Muestra los comandos disponibles | Cuando no recuerdes uno |
| Modo plan (`Shift+Tab`) | Claude solo lee y planifica, sin editar | Antes de cambios grandes |
| `/clear` | Borra la conversación | Al cambiar de tarea |
| `/compact` | Resume la conversación | Sesiones largas |
| `/model` | Cambia de modelo | Según la dificultad de la tarea |
| `/init` | Crea `CLAUDE.md` | Al empezar un proyecto |
| `/resume` | Retoma una conversación anterior | Al volver a un trabajo |
| `/code-review` | Revisa los cambios buscando bugs | Antes de cada PR |
| `/simplify` | Simplifica el código modificado | Tras terminar una funcionalidad |
| `/security-review` | Revisa la seguridad de los cambios | Antes de subir cambios sensibles |
| `/loop` | Repite una tarea cada cierto intervalo | Vigilar un pipeline |

## Persistencia entre sesiones
- `CLAUDE.md` (en el repo): convenciones y contexto del proyecto.
- Memoria personal (fuera del repo): quién eres y cómo prefieres trabajar.
- `/resume`: retoma una conversación concreta.
